# 邮箱后台更新

已登录工作台在布局层维护一条经过 Bearer 身份认证的 SSE 连接，无需进入邮件中心。浏览器标签页隐藏时，服务器仍负责邮箱同步，变化通过事件更新侧边栏未读数和已打开的邮件列表。自动更新不清空列表、不切换当前邮件、不显示刷新转圈或重复错误提示。

- 默认同步频率为“实时”：正常网络下约每 15 秒检查一次服务商，再推送变化；不是服务商 IMAP IDLE 的零延迟通知。
- 已保存的“手动”“每小时”“每天”配置继续生效；停用邮箱或邮件应用后停止相应自动同步。未读徽章独立于弹窗通知开关。
- 同一用户的多个标签页共享服务器同步任务。手动与自动请求共享账户正在执行的同步，避免重复连接；失败账户退避重试，不阻塞其他账户。
- 按 UIDVALIDITY 和 UID 复用已经缓存的正文，只为新邮件读取 MIME，继续同步服务商的已读和星标状态。同步不把收件自动标记为已读。
- SSE 中断后自动重连；连接不可用时，工作台回退到静默轮询。断网保留最近成功的数据，恢复联网后重试；退出登录会关闭订阅。
- 后台任务跟随工作台连接存在。关闭所有工作台标签页后释放任务；本功能不提供浏览器关闭后的系统推送。

原有收件箱缓存窗口（最近 200 封）和本地归档、回收站语义保持一致。
