# AI 流式对话与模型管理

AI 回复使用服务商的真实 SSE 增量输出。聊天正文不显示头像；空会话仍保留工作台的 AI 动画。对话布局复用 shadcn 的 Message、Bubble 和 Message Scroller，生成状态、推理过程和工具请求使用 Marker。Markdown 代码围栏使用 Base UI Code Block，支持按语言高亮、行号与复制；原始 HTML 不会执行。

## 使用方式

在「账户设置 → AI 配置」中保存服务商、接口地址与密钥，点击「保存并获取模型」获取该凭据可访问的模型。逐项选择启用的模型，并选择默认模型后保存。服务商不提供兼容的模型列表接口时，可手动填写模型 ID。

「启用 AI 服务」控制是否可以生成新回复。关闭服务不会删除密钥和会话；停用默认模型时自动选择剩余已启用模型，停用最后一个模型时自动关闭服务。保存后 AI 页面立即更新，无需刷新。

生成时点击输入框右下角的「停止生成」取消请求。已显示的部分文本会保留并明确标记为未完成，输入也会保留供重试。只有完整生成的用户消息与回答才保存到会话历史。推理过程只在当前页面展示，不写入消息历史。

## 接口

- `GET /ai/models`：服务端使用已加密保存的凭据请求服务商的 `/models`，返回模型 ID 列表，不向浏览器返回密钥。
- `POST /ai/conversations/{id}/stream`：请求体为 `{ "content": "问题" }`，返回 `text/event-stream`。
- SSE 事件包括 `reasoning`、`content`、`activity`、`done` 和 `error`；文本增量为 `{ "delta": "文本" }`，`done` 返回已保存的消息与会话。
- 上游请求 `stream: true`，保留既有非流式消息接口。超时、断线、Token 上限和工具请求未执行等情况均明确报错，不把部分回答保存为成功结果。

工具 Marker 只反映真实收到的请求或状态；当前兼容接口尚未配置可执行工具，不会把工具请求显示为已成功执行。

密钥继续由服务端加密保存。变更接口地址时需要填写对应的新密钥，不能将旧凭据转发到另一地址。
